# 製品仕様 v0.1

## 対象と範囲

- 対象機種はM5Stack Paper Mono C153のみとする。
- スマホアプリはAndroidとiPhoneを同一Flutterプロジェクトで提供する。
- 通信はNFCのみとし、Wi-Fi、BLE、クラウド、OTAを実装しない。
- 画像はスマホからPaper Monoへの一方向転送とする。
- Paper MonoからスマホへはACK、進捗、エラーを返す。

## 通常画面

既存の480 x 800白黒カードUIを踏襲し、次を表示する。

1. 上部ステータスバーとバッテリー残量
2. 386 x 386のデフォルト画像またはDASH受信画像（FULL受信画像は480 x 800全面表示）
3. 日付、大きな時計、今日の歩数カード
4. 7日間カレンダーストリップ
5. 変更可能な歩数目標と20セグメントの進捗カウンター

日付部分のタップで月間カレンダー、歩数カードのタップで履歴を開く。

## メニュー

通常画面でBtnAを700 ms長押しして、2列 x 3行のメニューを開く。

| 項目 | 動作 |
| --- | --- |
| RECEIVE IMAGE | NFC画像受信待機へ入る |
| SYNC CLOCK | NFC時刻同期待機へ入る |
| STEP GOAL | 1,000～50,000歩を1,000歩単位で設定する |
| STEP HISTORY | 30日履歴を7日単位で表示し、表示月の保存済み記録日平均を表示する |
| RESET IMAGE | デフォルトへ戻す、選択削除、全受信画像削除を行う |
| IMAGE LIBRARY | 保存画像を6枚ずつ表示し、表示選択と複数削除を行う |

メニューではBtnA短押しで次項目、BtnB短押しで決定、BtnA長押しで閉じる。
画面カードの直接タップにも対応する。
カードは番号、項目名、選択状態だけを表示し、操作案内は読みやすい下部フッターへ
まとめる。各機能画面の操作案内も同じ文字サイズとフッター表現を使用する。

## 画像

- `firmware/assets/default.jpg`をビルド時にアプリ本体へ埋め込む。
- デフォルト画像は386 x 386、8-bit baseline JPEG、3コンポーネント、
  256 KiB以下とする。
- NFC受信画像は最大17枚、埋め込みデフォルト画像を含めて合計18枚とする。
- 386 x 386のダッシュボード画像と480 x 800の全画面画像を扱う。
- 新しい受信画像を先頭へ追加して即時表示し、上限超過時は最古画像を削除する。
- IMAGE LIBRARYは2列 x 3行、最大3ページとし、DASH/FULL、現在画像、最新画像を示す。
- 現在表示中の画像は`OK`、BtnAの`NEXT`で移動する操作フォーカスは黒い太枠で
  明示する。通常フッターはBtnA長押しの通常画面復帰、BtnB長押しの削除モードの
  順で表示する。
- 受信画像は名前を持たず、カードには新しい順の番号を表示する。
- 左右スワイプ、矢印、ページドット、物理ボタンで操作できる。
- 削除モードは複数選択に対応し、デフォルト画像は削除できない。
- CRCとJPEG検証、ファイル保存、メタデータ保存が完了してから表示を切り替える。
- 中断、CRC不一致、形式不正、電源断では以前の画像を維持する。

`RESET IMAGE`はデフォルトへ戻す、選択削除、全受信画像削除を提供する。
RTC、タイムゾーン、歩数、履歴、目標は削除しない。

## スマートフォンアプリ

- 1つのFlutterプロジェクトからAndroid版とiPhone版を提供する。
- 初回表示は日本語とし、アプリ内で日本語／英語を切り替えて選択を端末へ保存する。
- UI、進捗、エラー、iPhoneのCore NFCシートを選択言語へ揃える。
- `時計と表示`（DASH、386 x 386）と`全画面`（FULL、480 x 800）を送信前に選ぶ。
- ギャラリーとカメラから画像を選び、固定比率で切り抜き、最終JPEGと同じ
  モノクロプレビューを表示する。
- 画像名やユーザー入力メタデータは送信しない。
- 画像送信と時刻同期は独立したボタンとセッションにする。
- 未完了画像、モード、CRC、Transfer IDをアプリ内へ一時保存し、タグロスト後の
  再開に使用する。ファームウェアの保存完了後に一時データを削除する。
- 送信中は進捗、再試行可能なエラー、キャンセル、完了を表示する。
- 保存完了または時刻同期完了を終端状態として扱い、進捗バーを停止して完了表示を
  約2秒後に自動で閉じる。エラー表示は手動で閉じるまで残す。

## 時刻

- RX8130CE RTCにはUTCを保存する。
- スマホは64-bit Unix時刻とUTCオフセット（分）をNFCで送信する。
- 画像送信と時刻同期は独立した操作とし、画像送信は時刻同期を前提にしない。
- 画像送信では`SET_TIME`を送らず、時刻同期非対応の画像受信機とも互換性を保つ。
- `SYNC CLOCK`では画像なしで時刻のみ同期できる。
- 時刻同期成功後は完了メッセージ画面を挟まず、更新した時刻を表示する通常画面へ戻る。
- RTC無効時は時計を`--:--`、日付を未設定表示にする。
- 初回同期前に集計した歩数は、同期後のローカル日へ割り当てる。

## 歩数

- BMI270の加速度のみを使い、ジャイロは省電力時に停止する。
- 30日分の`日付・歩数・当日の目標値`をNVSへ保存する。
- 目標初期値は10,000歩、範囲は1,000～50,000歩とする。
- 日次切り替えはスマホから同期したUTCオフセットを反映したローカル日付で行う。
- Flash保存は歩数差分、時間間隔、状態遷移時にまとめて行う。
- 端末比較で過大計数だった旧1.8倍補正を9/7倍へ再校正し、ケイデンス判定を通過した
  歩行周期だけに適用する。既存の日次履歴は遡って変更しない。

## 省電力

- 通常画面のBtnB短押しでLowPowerLockedへ入る。
- 画像、時計、日付、歩数、目標を電子ペーパーに残す。
- フロントライト、タッチ、NFC、RGB LED、ブザー、ジャイロを停止する。
- RTCと加速度サンプリングを維持し、サンプル間はlight sleepする。
- 時計と歩数の表示は1分ごとに下部領域だけ更新する。
- 全画面画像では時計・歩数の部分更新を行わず、画像全体を保持する。
- バッテリー残量はPMIC電圧を3,300mV=0%、4,200mV=100%として換算し、微小変動を
  平滑化する。読取エラー時は直前の正常値を維持し、正常値がない場合は`--%`とする。
- BtnB短押しでタッチを復旧し、フロントライトを戻す。
- NFC画像受信・時刻同期待機中はBtnA長押しでキャンセルして通常画面へ戻る。
- NFC待機中のBtnB短押しでは画面遷移しない。

## 受け入れ条件

- アプリファームウェアだけを書き込み、デフォルト画像付きで起動できる。
- AndroidとiPhoneから実機へ画像と時刻を送信できる。
- 失敗、キャンセル、再起動で最後の正常画像を失わない。
- 歩数目標と30日履歴が再起動後も保持される。
- 省電力中も歩数が増え、BtnBで通常画面へ復帰できる。
- Wi-Fi/BLE/インターネット権限を要求しない。
