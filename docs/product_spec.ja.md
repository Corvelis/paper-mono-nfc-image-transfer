# 製品仕様 v0.1

## 対象と範囲

- 対象機種はM5Stack Paper Mono C153のみとする。
- スマホアプリはAndroidとiPhoneを同一Flutterプロジェクトで提供する。
- 通信はNFCのみとし、Wi-Fi、BLE、クラウド、OTAを実装しない。
- 画像はスマホからPaper Monoへの一方向転送とする。
- Paper MonoからスマホへはACK、進捗、エラーを返す。

## 通常画面

既存の480 x 800白黒カードUIを踏襲し、次を表示する。

1. 上部ステータスバーとバッテリー残量
2. 386 x 386のデフォルト画像またはNFC受信画像
3. 画像種別キャプション
4. 日付、大きな時計、今日の歩数カード
5. 7日間カレンダーストリップ
6. 変更可能な歩数目標と20セグメントの進捗カウンター

日付部分のタップで月間カレンダー、歩数カードのタップで履歴を開く。

## メニュー

通常画面でBtnAを700 ms長押しして、2列 x 3行のメニューを開く。

| 項目 | 動作 |
| --- | --- |
| RECEIVE IMAGE | NFC画像受信待機へ入る |
| SYNC CLOCK | NFC時刻同期待機へ入る |
| STEP GOAL | 1,000～50,000歩を1,000歩単位で設定する |
| STEP HISTORY | 30日履歴を7日単位で表示する |
| RESET IMAGE | 確認後に受信画像を削除する |
| BACK | 通常画面へ戻る |

メニューではBtnA短押しで次項目、BtnB短押しで決定、BtnA長押しで閉じる。
画面カードの直接タップにも対応する。

## 画像

- `firmware/assets/default.jpg`をビルド時にアプリ本体へ埋め込む。
- デフォルト画像は386 x 386、8-bit baseline JPEG、3コンポーネント、
  256 KiB以下とする。
- NFC受信画像はLittleFSのA/Bスロットへ交互に保存する。
- CRCとJPEG検証、ファイル保存、メタデータ保存が完了してから表示を切り替える。
- 中断、CRC不一致、形式不正、電源断では以前の画像を維持する。

`RESET IMAGE`はアクティブ画像を先にデフォルトへ切り替えてからA/Bスロットと
未完了一時データを削除する。RTC、タイムゾーン、歩数、履歴、目標は削除しない。

## 時刻

- RX8130CE RTCにはUTCを保存する。
- スマホは64-bit Unix時刻とUTCオフセット（分）をNFCで送信する。
- 画像送信開始時にも時刻を自動同期する。
- `SYNC CLOCK`では画像なしで時刻のみ同期できる。
- RTC無効時は時計を`--:--`、日付を未設定表示にする。
- 初回同期前に集計した歩数は、同期後のローカル日へ割り当てる。

## 歩数

- BMI270の加速度のみを使い、ジャイロは省電力時に停止する。
- 30日分の`日付・歩数・当日の目標値`をNVSへ保存する。
- 目標初期値は10,000歩、範囲は1,000～50,000歩とする。
- 日次切り替えはスマホから同期したUTCオフセットを反映したローカル日付で行う。
- Flash保存は歩数差分、時間間隔、状態遷移時にまとめて行う。

## 省電力

- 通常画面のBtnB短押しでLowPowerLockedへ入る。
- 画像、時計、日付、歩数、目標を電子ペーパーに残す。
- フロントライト、タッチ、NFC、RGB LED、ブザー、ジャイロを停止する。
- RTCと加速度サンプリングを維持し、サンプル間はlight sleepする。
- 時計と歩数の表示は1分ごとに下部領域だけ更新する。
- BtnB短押しでタッチを復旧し、フロントライトを戻す。
- NFC受信中のBtnBは省電力ではなく受信キャンセルとして扱う。

## 受け入れ条件

- アプリファームウェアだけを書き込み、デフォルト画像付きで起動できる。
- AndroidとiPhoneから実機へ画像と時刻を送信できる。
- 失敗、キャンセル、再起動で最後の正常画像を失わない。
- 歩数目標と30日履歴が再起動後も保持される。
- 省電力中も歩数が増え、BtnBで通常画面へ復帰できる。
- Wi-Fi/BLE/インターネット権限を要求しない。
