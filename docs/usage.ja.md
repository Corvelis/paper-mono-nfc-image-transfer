# 操作ガイド

この文書は、Paper Mono NFC Image Transferのスマートフォンアプリと
M5Stack Paper Mono C153を日常的に使うための操作一覧です。
インストール前は[配布バイナリのインストール](install_binary.ja.md)を参照してください。

スマートフォンアプリ右上の言語アイコンから`日本語`または`English`を選べます。
初回は日本語で、選択した言語は次回起動時も維持されます。

## 1. 物理ボタンの基本

ボタンの長押し判定は約700 msです。

| 画面 | BtnA | BtnB |
| --- | --- | --- |
| 通常画面 | 長押しでメニュー | 短押しで省電力ロック／復帰 |
| メニュー | 短押しで次、長押しで通常画面 | 短押しで開く |
| NFC待機 | 長押しでキャンセル | 使用しない |
| Image Library | 短押しで次、長押しでメニュー | 短押しで表示、長押しで削除モード |
| Image Library削除中 | 短押しで次、長押しで削除解除 | 短押しで選択、長押しで削除実行 |
| Step Goal | 短押しで-1,000、長押しで戻る | 短押しで+1,000、長押しで保存 |
| Step History | 短押しで次ページ、長押しで戻る | 短押しで前ページ |
| Reset Image | 短押しで次、長押しで戻る | 短押しで決定 |

電源キーはデバイスの電源制御用として予約しています。通常操作には使用しません。
FULL画像の表示中は画面タップを受け付けませんが、BtnA長押しとBtnB短押しは使えます。

## 2. 画像を送る

画像送信と時刻同期は独立しています。画像送信の前に時刻を合わせる必要はなく、
画像を送ってもデバイスの時計は変更されません。

1. スマートフォンアプリの`表示レイアウト`で次のどちらかを選ぶ。
   - `時計と表示`: 386 x 386のDASH画像。時計、日付、カレンダー、歩数と一緒に表示。
   - `全画面`: 480 x 800のFULL画像。時計などを重ねず、画面全体へ表示。
2. `ギャラリー`または`カメラ`から画像を選ぶ。
3. 切り抜き位置を調整し、`モノクロプレビューを生成`を押す。
4. Paper Monoの通常画面でBtnAを長押しし、`RECEIVE IMAGE`を開く。
5. アプリの`NFCで送信`を押し、スマートフォンのNFCアンテナをPaper Monoの
   NFC部分へ当てる。
6. アプリに保存完了が表示されるまで位置を保つ。

保存完了後は進捗バーが停止し、完了表示は約2秒後に自動で閉じます。エラーが発生した
場合は、内容を確認できるよう手動で閉じるまで表示されます。

通信が途中で切れた場合、同じプレビューから再送すると保存済みの位置から再開します。
別の画像やレイアウトを選ぶと、新しい送信として準備し直します。Paper Mono側の
NFC待機は約60秒で終了します。

## 3. 時刻を合わせる

1. Paper Monoのメニューで`SYNC CLOCK`を開く。
2. アプリ上部の`NFCで時刻を同期`を押す。
3. 完了するまでスマートフォンをNFC部分へ当てる。

スマートフォンのUTC時刻と現在のUTCオフセットが送られます。同期後はローカル日付を
基準に歩数の日次記録を切り替え、Paper Monoは完了画面を挟まず通常画面へ戻ります。
画像を選択しておく必要はありません。

## 4. Image Library

ライブラリには受信画像を最大17枚保存し、削除できないデフォルト画像を加えた
合計18枚を表示します。1ページは2列 x 3行の6枚で、最大3ページです。

- 並び順は新しい受信画像が先頭、デフォルト画像が最後。
- 新着画像には`NEW`、現在表示中の画像には`OK`を表示する。
- BtnAの`NEXT`で移動する操作フォーカスは黒い太枠で示す。
- `DASH`は時計と一緒に表示する画像、`FULL`は全画面画像。
- 画像名は送信しないため、受信画像は新しい順の番号で表示。
- 18枚目の受信画像を保存すると、最も古い受信画像を自動削除。

### 表示画像を選ぶ

- サムネイルをタップすると、その画像へ切り替えて通常画面へ戻る。
- 左右スワイプ、下部の矢印、ページドットでページを移動する。
- 物理ボタンではBtnA短押しで選択を進め、BtnB短押しで表示する。
- BtnA長押しでメニューを経由せず通常画面へ戻る。

### 画像を削除する

1. ヘッダーの`DELETE`をタップするか、BtnBを長押しして削除モードへ入る。
2. サムネイルをタップするか、BtnB短押しで削除対象を複数選ぶ。
3. 下部の`DELETE n`をタップするか、BtnBを長押しして削除する。

`CANCEL`またはBtnA長押しで選択を破棄します。`LOCK`と表示されるデフォルト画像は
削除できません。表示中の受信画像を削除した場合はデフォルト画像へ戻ります。
通常画面のフッターは`HOLD A: BACK`、`HOLD B: DELETE`の順で表示します。

## 5. Reset Image

`RESET IMAGE`には次の3項目があります。

| 項目 | 動作 |
| --- | --- |
| `USE DEFAULT` | 受信画像を残したままデフォルト画像へ切り替える |
| `DELETE SELECTED` | Image Libraryの複数選択削除を開く |
| `DELETE ALL RECEIVED` | 確認後、受信画像だけをすべて削除する |

いずれの操作でもデフォルト画像、時計、タイムゾーン、歩数履歴、歩数目標は削除しません。

## 6. 歩数目標と履歴

`STEP GOAL`では1,000～50,000歩を1,000歩単位で選びます。画面の`-`/`+`を
タップするかBtnA/BtnB短押しで変更し、`SAVE`またはBtnB長押しで保存します。

`STEP HISTORY`は30日分を7日ずつ表示します。BtnA/BtnBで次／前ページへ移動し、
下部をタップするかBtnA長押しで戻ります。`AVG`は表示対象月に保存されている
日次記録の平均歩数です。

歩数は加速度から推定するため、スマートフォンとの装着位置や歩き方の違いにより多少の
差が出ます。補正変更後も保存済み履歴はそのまま残り、新しく検出した歩数から反映されます。

## 7. 省電力ロック

通常画面でBtnBを短押しすると、表示内容を保ったまま省電力ロックへ入ります。
`LOW POWER`などの追加文字は画面へ重ねません。

- フロントライト、タッチ、NFC、RGB LED、ブザー、ジャイロを停止。
- RTCと加速度による歩数計測を継続。
- DASH表示では時計と歩数を約1分ごとに部分更新。
- FULL表示では画像を変更せず、そのまま保持。

右上のバッテリー残量は3.3～4.2Vを0～100%へ換算した目安です。電圧を平滑化して
表示のふらつきを抑え、読み取りに一時失敗した場合は直前の正常値を維持します。

もう一度BtnBを短押しすると通常状態へ戻り、フロントライトとタッチを復旧します。

## 8. 困ったとき

- 画像送信で時刻同期エラーになる: アプリとファームウェアを同じ最新Releaseへ更新する。
- NFCを認識しない: Paper Mono側の待機画面とアプリの操作が一致しているか確認する。
- 転送が途切れる: スマートフォンのNFCアンテナ位置を探し、完了まで動かさない。
- Androidで`Tag is out of date`が発生する: 最新アプリでは新しいNFCタグ接続へ自動で
  引き継ぎます。完了表示が出るまでPaper Monoへ当てたままにしてください。
- 新しい画像が見つからない: Image Libraryの1ページ目に`NEW`があるか確認する。
- 画像を初期状態へ戻したい: `RESET IMAGE` → `USE DEFAULT`を選ぶ。
